# Currency Converter

A small React and TypeScript currency converter using the CurrencyBeacon API.

## Run locally

1. Create a free CurrencyBeacon account and copy your API token.
2. Create a `.env` file in the project root:

```env
VITE_CURRENCYBEACON_API_KEY=your_api_key_here
```

3. Install dependencies and start Vite:

```bash
npm install
npm run dev
```

The Vite proxy forwards `/api/currencybeacon` requests to the CurrencyBeacon API.

## Decisions

- Currency options are loaded from the currencies endpoint instead of being hard-coded.
- Conversion runs after a short debounce when the amount or selected currencies change.
- The API key is read from an environment variable. Because this is a frontend app, the key is still visible in browser requests; a production app should call the API through a server-side backend.

```bash
npm run lint
npm run build
```

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Oxc](https://oxc.rs)
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) uses [SWC](https://swc.rs/)

## React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).
